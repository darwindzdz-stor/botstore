# التطوير المستمر لنفس المشروع

هذه ليست نسخًا منفصلة. كل تحديث يجب أن يعدّل هذا المشروع وقاعدة بياناته مع migrations متوافقة.

المرحلة التالية المقترحة داخل نفس الشجرة:
- بحث Full-Text أكثر دقة
- إدارة متقدمة من CLI
- Moderation queue
- إشعارات Telegram
- إدارة فئات/Tags من CLI
- صفحات عامة للبوتات
- caching
- Cloudflare Workers/D1 adapter
- نظام Featured/Verified أكثر صرامة
- تحليلات زمنية
- نظام backup/restore مع تحقق من سلامة النسخة
